Settings

Voice

✈️ = works offline · 🌐 = needs internet. Only languages and accents installed on this device are listed.

Don't see your language or accent? Add voices on the device

Windows 11: Settings → Time & language → Speech → Add voices.
iPhone / iPad: Settings → Accessibility → Spoken Content → Voices.
Mac: System Settings → Accessibility → Spoken Content → System voice → Manage Voices.
Android: Settings → Accessibility → Text-to-speech → Preferred engine → Install voice data.
Chromebook: Settings → Accessibility → Text-to-speech → Text-to-speech engine settings.
Then close and reopen TalkBoard.

Display

Pick a template (for example 2, 4 or 9 buttons) to show fewer, bigger buttons with page arrows. "Show all" fits every button on one screen using the Columns setting. Each board can also have its own template: open it in Edit mode and press Layout.

Access

Scanning: the highlight moves by itself. Press Space, Enter, or a connected switch (or tap anywhere) to choose the highlighted item.

Child profile

Editing

Hides the Edit button so the person can't change things by accident. To get back here, press and hold the ⚙️ button for 2 seconds.

Backup & restore

Copy a backup (all boards, photos and settings) and keep it somewhere safe, such as an email to yourself or a note. On a new or replaced device, paste it here (or choose a saved backup file) and press Restore.
